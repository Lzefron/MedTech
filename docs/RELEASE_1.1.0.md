# MedTrack 1.1.0

- Test entry comes first, with all tests available to browse or type.
- Prominent bordered Today and Skip buttons simplify report details.
- Common units are filled for built-in tests, with editable suggestions and a browsable list.
- General adult reference ranges include medical sources and supported unit conversions. Select the appropriate adult group once per entry session; copy the lab's range or skip when no verified suggestion applies.
- Reference provenance remains visible in records, trends and PDF exports.
- Database migration preserves existing profiles, reports and medicines.
- Android target updated to API 36; version code 2.

Install **MedTrack-v1.1.0.apk** on your phone. Upload **MedTrack-v1.1.0.aab** to Google Play Console. Both use the existing private release/upload key. SHA256SUMS.txt verifies the downloads. Signed 1.0.0 installations can update in place; older debug installations use a different certificate and cannot be overwritten with this release.

Ranges are general references, not diagnoses. See docs/REFERENCE_RANGES.md in the repository for sources and coverage. Children, pregnancy and treatment targets require the laboratory's reference interval.
